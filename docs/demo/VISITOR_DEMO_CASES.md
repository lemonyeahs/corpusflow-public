# 现场案例卡

## 案例一：真实处理链

从 Asset 进入处理中心，查看解析 Run、DocumentVersion、Segment 与三栏对照。案例状态由 `GET /api/v1/demo/cases` 动态决定；缺少记录时停止在“数据未准备”说明页。

## 案例二：质量异常与恢复

选择已有质量问题，查看原文证据、问题状态和审核记录。驳回状态不能恢复；审核通过后必须重新执行允许的节点。页面不以按钮可见性代替后端授权。

## 案例三：数据产品与下载

打开已发布版本，核对 Manifest、SHA-256、样本数、来源和短期签名下载。下载内容必须与 Manifest 哈希一致；没有真实版本时显示空状态。

## 案例四：反馈重工

只有当 Trace、反馈、重工 Run、新版本和评测记录全部在当前 workspace 存在时，才展示完整反馈链。当前缺失的历史 KEM 对象标记为 `MISSING`，不使用复制记录补齐。
