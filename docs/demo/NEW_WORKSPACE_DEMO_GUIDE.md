# CorpusFlow 新工作台演示指南

## 启动

1. 在仓库根目录执行 `make init-env`（仅首次执行）和 `make up`。
2. 启动 Web：`npm --prefix apps/web ci`，再执行 `npm --prefix apps/web run dev -- --host 127.0.0.1`。
3. 打开 `http://127.0.0.1:5173/`，使用开发环境登录创建或选择 workspace。

## 演示流程

### 1. 上传论文并识别元数据

1. 进入「数据接入」，创建或选择来源。
2. 一次选择 PDF、Markdown、JSON 或 HTML 文件，点击「上传并登记」。
3. 观察每个文件独立的上传进度、校验、登记状态。服务端计算 SHA-256、文件大小并写入对象存储。
4. 登记完成后，文件行显示自动识别的标题和文档类型候选。候选状态仍为待确认。

### 2. 人工确认

1. 进入「资产中心」，打开刚上传的资产。
2. 查看 SHA-256、MIME、解析状态和「自动识别结果」来源。
3. 点击「确认并保存」。确认人、确认时间和审计事件会写入数据库；取消确认前，候选不会被当作正式元数据。

### 3. 总览与资产检索

1. 返回「总览」，查看八种文件格式卡片。没有数据的格式显示 0，不产生演示数字。
2. 点击某个格式卡片，进入带 `file_format` 筛选的资产中心。
3. 在资产详情中通过文档对照和数据血缘查看已有解析产物与来源关系。

### 4. 数据加工

1. 进入「处理中心」，选择已有资产并提交处理运行。
2. 等待既有 Worker 完成解析和物化；失败运行在页面中显示真实错误，可按既有流程重试。

### 5. SFT 样本查看

1. 进入「SFT 数据集」，选择 `product_type=sft` 的真实数据集。
2. 在「真实 SFT 样本浏览」中按 Prompt/Answer 搜索。
3. 展开样本查看 `messages` JSON、版本、split、来源 Asset 和状态。没有已物化样本时页面显示空状态，并引导回构建流程。

### 6. DPO 偏好样本查看

1. 进入「DPO 偏好数据集」，页面读取真实 `PreferenceSample`。
2. 选择样本查看 Prompt、Response A/B、审核状态、来源和证据 Segment。
3. 只有已有真实候选、授权和审核记录的偏好对才能进入构建与发布；空 workspace 不会生成随机样本。

## 常见问题

- 元数据提取失败时，原始 Asset 仍保留在资产中心；可通过候选详情执行重试。
- PDF 是文件格式，不代表具有训练授权。训练用途仍需走现有授权证据与确认流程。
- 外部模型、GROBID、Crossref 和 OCR 不会被默认调用；需按项目配置和授权显式启用。
