# P2-Closure 收敛计划

基线 99533a5。保留业务模块、历史发布和原型，不增加模型额度，本轮优先零新模型调用。

1. 采集：核对宿主/容器 DNS、连接地址及代理；补齐地址/重定向/慢响应/长度检查。用自建本地 HTTPS 服务传输实际字节并验证登记与对象哈希；测试注入仅在隔离进程，不增加生产绕过开关。公网成功仍依真实网络结果判定。
2. 复杂 PDF：创建许可明确的自制真实多栏、表格、公式、图片/扫描 fixture，保存设计参考与 SHA。比较内置、OCR、Poppler 版面适配器；保留失败与 NOT_EVALUATED，不把作者参考称为专家标注。
3. 评测：新增冻结任务/分配的最小表，复用 RetrievalReview。盲评响应不泄漏模型/策略/他人评分；授权重新检查；固定 rubric、原文证据、分配身份、不可变提交、管理员导出及一致性统计。真实专家仍待参与。
4. 验收：先迁移/单元与独立集成，再全新 Docker 构建及真实 Web，最后隔离 Worker 故障和备份恢复。记录失败与修复，更新演示/验收后本地提交，不 push。

门禁：冻结版本不改写；权限及用途失败拒绝；任务/评分幂等；真实依赖测试不得 Mock。复杂文档指标仅适用于明确参考集，不泛化成专业领域高保真保证。
